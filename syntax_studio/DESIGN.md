## Brand & Style

This design system establishes an ultra-refined, editorial-grade digital home and content management interface for graphic designer Abdullah. The aesthetic fuses austere Swiss minimalism with contemporary glassmorphic luminescence. 

The visual personality rests on three pillars:
- **Architectural Discipline:** Structural alignment, generous spatial breathing room, and immaculate hierarchy convey uncompromising creative standards.
- **Luminescent Accentuation:** Electric violet and lilac highlights create intentional focal moments without overwhelming the creative work on display.
- **Tactile Weightlessness:** Soft drop shadows, frosted translucent backdrops, and pill-formed micro-surfaces create a tactile, floating spatial experience.

Targeting creative directors, luxury brand founders, and discerning cultural institutions, the interface retreats gracefully to let portfolio work command focus, while providing a tactile, studio-grade CMS editing environment.

## Colors

The palette is engineered to provide high legibility, soft atmospheric layering, and electric visual interest through calibrated color roles:

- **Canvas & Surface Base:** The foundation rests on off-white tones (`#F8F9FC` for page canvas, `#FFFFFF` for pristine cards). This prevents clinical glare while maintaining an editorial gallery feel.
- **Deep Contrast Typography:** Headlines and interactive text leverage near-black (`#080808` and `#111111`) for crisp graphic impact. Muted body and metadata utilize cool gray (`#667085`).
- **Accent Radiance:** Primary interactive accents leverage vibrant electric violet (`#6C3BFF` with hover state `#5825E3`). Soft lilac containers (`#EEE9FF` and `#F4F1FF`) provide tinted backgrounds for tags, active workspace regions, and floating badges.
- **Structural Outlines:** Fine hairline borders (`#DDE1EA` and `#ECEFF5`) frame content blocks with subtle architectural precision.

## Typography

The typographic hierarchy juxtaposes bold geometric display styling with systematic editorial clarity and functional technical labels:

- **Display & Headings (Space Grotesk):** Provides structured personality with distinctive geometric ink-traps and disciplined proportional rhythm. Letter-spacing is intentionally tightened at larger scales to evoke contemporary printed monographs.
- **Body Text (Hanken Grotesk):** Balances high legibility with an understated modern grotesque voice, ensuring long-form case studies, design documentation, and CMS editorial metadata remain effortless to read.
- **Metadata & Technical Microcopy (JetBrains Mono):** Sets project indices, dimensions, timestamps, tags, and CMS state badges in crisp monospaced characters, establishing clear demarcation between creative content and system mechanics.

## Layout & Spacing

The layout is built upon an asymmetric 12-column grid that translates smoothly between dynamic full-bleed presentation and disciplined content management dashboards.

- **Breakpoints & Layout Scaling:**
  - **Desktop (1280px+):** Max-width container of 1440px with `margin-lg` (5rem) margins and `gutter-lg` (2.5rem) column spacing. Generous section breathing room utilizes `space-2xl` and `space-3xl` intervals.
  - **Tablet (768px - 1279px):** 8-column layout with `margin-md` (3rem) side padding and standard `gutter` (1.5rem). CMS view adapts to collapsible dual-column panels.
  - **Mobile (< 768px):** 4-column flow with `margin` (1.5rem) margins. Large hero text downscales cleanly, and floating toolbars dock to the bottom viewport edge for thumb ergonomics.

- **Editorial Rhythm:** Grid spacing is strictly enforced through an 8pt spatial baseline. Whitespace functions as an active compositional material, separating high-density CMS controls from expansive project viewports.

## Elevation & Depth

Visual depth is achieved through translucent planar layering, diffused colored ambient glows, and razor-sharp border outlines:

- **Frosted Translucency:** Floating navigation rails, action docks, and context menus employ glassmorphism using semi-transparent white backgrounds (`rgba(255, 255, 255, 0.72)`) paired with `backdrop-filter: blur(20px)` and an inner highlight rim (`box-shadow: inset 0 0 0 1px rgba(255, 255, 255, 0.6)`).
- **Subtle Ambient Shadows:** Standard elevated cards utilize deep, non-directional atmospheric drop shadows (`0 20px 40px -15px rgba(8, 8, 8, 0.05), 0 0 1px rgba(8, 8, 8, 0.08)`).
- **Vibrant Accent Halos:** Primary callouts, active CMS drag-states, and hero CTAs cast a localized, diffused violet aura (`0 12px 28px -6px rgba(108, 59, 255, 0.28)`), creating an illuminated lifting sensation without visual muddiness.
- **Hairline Boundary Separation:** All floating surfaces and segmented panels sit atop crisp 1px borders (`#DDE1EA` or `rgba(221, 225, 234, 0.7)`), grounding the translucent effects with graphic precision.

## Shapes

The design system adopts a pill-shaped curvature standard (Level 3) that sharply contrasts against strict rectangular grid modules:

- **Capsule Elements (Pill Standard):** Interactive buttons, navigation pills, status badges, and search bars use complete border radius curves (`rounded-full` / `9999px`), imparting a refined, sculpted hand-feel.
- **Medium Structural Cards:** Portfolio project previews, asset containers, and CMS panels utilize relaxed curves (`rounded-2xl` / 2rem), keeping viewport geometry soft yet modern.
- **Micro UI & Inputs:** Text inputs, nested control groups, and segmented toggles use a disciplined `rounded-xl` (1rem) curvature to maintain layout efficiency and clean interior padding.

## Components

### Buttons
- **Primary:** Full pill (`rounded-full`), solid `#6C3BFF` background with `#FFFFFF` label text. Glow shadow on resting; transitions to `#5825E3` with scaled aura on hover.
- **Secondary / Glass:** Pill shape, `rgba(255, 255, 255, 0.8)` surface with a 1px `#DDE1EA` hairline border, `#080808` text. Hover applies soft lilac tint (`#F4F1FF`) and shifts border to `#6C3BFF`.
- **Ghost:** Monospaced label in `#667085`, zero background, underlined on hover with `#6C3BFF`.

### Floating Navigation Pill
- Centered floating dock, fixed either top or bottom depending on context. Formed with frosted glass (`rgba(255, 255, 255, 0.75)`, 24px backdrop blur), thin `#DDE1EA` border, and nested pill active indicators highlighted with `#EEE9FF` background and `#6C3BFF` text.

### Portfolio & Asset Cards
- **Structure:** Opaque white base or glass card, framed with a 1px `#DDE1EA` perimeter. Hover states elevate with an ambient diffused shadow and trigger a subtle scale on media previews.
- **Meta Footer:** Integrated technical info strip with project title in Space Grotesk and monospaced category tags styled in small pill badges.

### CMS Inputs & Form Fields
- **Text Inputs:** `#FFFFFF` canvas, `rounded-xl` boundary, 1px border `#DDE1EA`. Focus state transitions border to `#6C3BFF` with an inner 2px glow ring of `#EEE9FF`.
- **Labels:** Set in JetBrains Mono (`label-sm`), uppercase with wide letter-spacing in `#667085`.

### Chips & Status Badges
- Pill-shaped badges using soft lilac (`#EEE9FF` or `#F4F1FF`) with deep purple (`#6C3BFF`) typography for active states, drafts, and categories. Static tags use off-white backgrounds with `#667085` text.

### Segmented Controls & Toggles
- Recessed pill trough with `#F4F1FF` background. The active state indicator is a smooth floating white capsule card bearing a micro shadow (`0 2px 8px rgba(0,0,0,0.06)`).

### CMS Case Study Editor Panel
- Floating inspector drawer with frosted backdrop glass, tabbed navigation in JetBrains Mono, and inline asset drag zones bounded by dashed `#DDE1EA` outlines that highlight to solid `#6C3BFF` on drag-over.
